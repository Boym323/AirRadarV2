### Korekce statického auditu před merge

Actionlint odhalil **skutečnou P0 chybu v release YAML** — u `publish-dev-candidate` byly dvě definice `if`. GitHub tak změněný workflow odmítal bez spuštění jobů. Nahrazeno jedinou podmínkou spojující `main`, název repozitáře a `g03_runtime=='false'`. Vedle toho actionlint 1.7.7 nesprávně označuje již existující `timezone: Europe/Prague` v **nezměněném** `development-metrics.yml` za nepovolenou položku; proto nový statický audit explicitně kontroluje pouze `ci.yml` a změněný release workflow, čímž nenarušuje rozvrh denních statistik. **Nový zelený run požadován** před merge.
